# <img src="public/icon.png" alt="" width="32" height="32"> 線上筆劃中文輸入

[English](README.en.md) · **[立即使用](https://stroke-cn-input.grok.me/)**

在瀏覽器裡用五類筆劃輸入漢字。英文鍵 `U I O J K L` 對應筆劃，選字之後，那些字母換成漢字。文字留在這一頁。

程式 MIT，字庫見 [NOTICE.md](NOTICE.md)。

## 這是什麼

打開網頁就能打中文，用的是筆順。

筆劃分成橫、豎、撇、點、折五類。提併進橫，豎鉤併進豎，捺併進點，其餘轉折都是折。按字的筆順打五類筆劃，從候選字裡選一個，就完成一個字。

頁面是靜態的：字庫下載到瀏覽器，選字、聯想、繁簡顯示都在本機完成，設定也存在本機。

筆順來自 [Conway Stroke Data](https://github.com/stroke-input/stroke-input-data)，約 28,000 字。

## 適合誰

- 認得那個字，但讀音不確定，或不想先想讀音。
- 在用別人的電腦、公用機器，或沒有自己輸入法設定的環境。
- 會寫字就夠，不用學拆字。
- 只想打幾個字，複製到別的地方。
- 要打繁體、簡體或粵語口語用字，希望自己決定顯示哪一種。

## 筆劃輸入的特性

- 以筆順為碼，只需知道那個字怎麼寫。
- 逐字輸入。選了一個字，下一個字會列出來，點一下就能接上。
- 前幾筆相同的字會一起出現，邊打邊看就能收窄。

## 特色

- **五類筆劃，一個通配。** 忘記某一筆按 `L`，對上那一筆的任何筆劃。
- **鍵盤或按鈕。** 用字母鍵打，或在畫面上點筆劃。
- **鍵位可換。** 預設 `UIOJKL`，也可改成 `JKLUIO`。
- **選字從 `9` 數起。** 第一個候選是 `9`，然後 `8` 到 `1`。`9` 在筆劃鍵旁邊，最常選的字就在手邊。標點和聯想也是這個次序。
- **可以單手打。** 筆劃鍵和 `9` 都在右手。按鈕模式用一隻手點也夠。
- **字集可選。** 繁體、簡體，或兩者並列。已打進文稿的字保持原樣。
- **偏好可調。** 可把一組粵語口語用字提前或押後，也可隱藏字頻表以外的字。
- **聯想字。** 選了一個字之後列出下一個字。再打一筆或選了標點就收起。
- **版面按打字來排。** 選字在上，文稿在下，筆劃貼著輸入的地方。

## 怎麼打

| 鍵（預設 `UIOJKL`） | 筆劃 |
|---|---|
| `U` | 橫 |
| `I` | 豎 |
| `O` | 撇 |
| `J` | 點 |
| `K` | 折 |
| `L` | 通配（任何一筆） |

其他按鍵：

| 鍵 | 作用 |
|---|---|
| `9`–`1` | 選當頁的字 |
| `B` | 開標點 |
| 空白 | 空格 |
| `←` `→` | 翻頁 |
| 退格 | 刪除 |
| `Esc` | 取消筆劃 |

按鈕模式直接點筆劃，左右滑動翻頁。觸控裝置上也可以點候選字。

### 試打

| 字 | 筆順 | 鍵 |
|---|---|---|
| 十 | 一 丨 | `U I` |
| 人 | 丿 丶 | `O J` |
| 口 | 丨 フ 一 | `I K U` |
| 木 | 一 丨 丿 丶 | `U I O J` |

### 幾個技巧

- **不確定某一筆，用 `L`。** 例如「木」忘了第四筆，打 `U I O L`。
- **打頭兩三筆即可。** 候選字會隨每一筆收窄。
- **選字之後看聯想列。** 下一個字可以直接點。

## 設定

- **字集**：繁體、簡體，或兩者。
- **去除罕用字**：隱藏字頻表以外的字。偏好選「粵語」時，那組口語用字仍會留下。
- **偏好**：「預設」沿用 Conway 的字頻來排候選字，聯想沿用事先算好的詞頻表。「粵語」把那組口語用字提前，「國語」把它們押後。
- **輸入方式**：鍵盤或按鈕。鍵位 `UIOJKL` 或 `JKLUIO`。

設定存在 `localStorage`（鍵名 `stroke-cn.v1`）。清除網站資料會回到預設。

## 隱私

打的字、選的字、文稿都在瀏覽器裡處理。字庫與程式以靜態檔下載。設定存在本機的 `localStorage`。

頁面會向 Google Fonts 取 Noto Sans TC 與 Noto Serif TC。這個請求會帶上 IP 與瀏覽器類型，不包含打進去的文字。

要離線使用，可自行 `npm run build`，把 `dist/` 放到本機或任何靜態主機。字型那時會改用系統字。

## 限制

- **筆順對得上就能找到。** 跟字庫不一致時可以改一筆，或用 `L` 跳過不確定的那一筆。
- **逐字輸入。** 長文的按鍵較多。
- **候選字較多。** 前幾筆相同的字要翻頁挑。
- **在此頁輸入。** 打完的字要複製到目標程式。
- **字集只篩選候選。** 已打進文稿的字不會被改成另一套字形。
- **字庫可能缺字，筆順也可能與你記得的不同。** 候選排序是統計結果。
- **設定會改變結果。** 開「去除罕用字」或只顯示繁／簡，某些字就不會出現。

## 開發

需要 Node.js 22 或以上。

```bash
npm install
npm test
npm run dev
```

`npm run dev` 會在本機開一個頁面。`npm run build` 會做型別檢查，並把靜態檔輸出到 `dist/`。字庫在 `public/dict/`，建置時會原樣複製過去。

```
src/ime/      筆劃對照、選字、聯想。可單獨測試。
src/ui/       介面。App 管輸入狀態，其餘是設定、說明、候選字。
public/dict/  字庫。授權見 NOTICE.md。
```

## 常見問題

**不懂筆順可以打嗎？**
可以打一部分：用 `L` 跳過不確定的筆，或只打頭幾筆再從候選字挑。

**某個字打不出來。**
先看三處：筆順是否與字庫一致、有沒有開「去除罕用字」、字集是不是只顯示繁或只顯示簡。

**手機可以用嗎？**
可以。按鈕模式直接點筆劃，也可以左右滑動翻頁。

**可以自己託管嗎？**
可以。`npm run build` 之後，`dist/` 就是完整的靜態站，字庫一併複製過去。
